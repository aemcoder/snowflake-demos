### Placeholder convention

This page uses a CSS class pattern: `class="ds-placeholder"` on containers.
These are NOT Stardust `data-placeholder="true"` attributes.
The `.ds-placeholder::after` CSS rule injects a "PLACEHOLDER" badge via `content:`.
Elements: 4 tweet cards (ds-tweet.ds-placeholder) and 3 how-it-works captions (ds-how__caption.ds-placeholder).
Mark these with `data-slot-skip="placeholder"` — not authorable slots.

### Switch panel background-image

`.ds-switch__panel` has inline `style="background-image: url('https://marketing-edge-assets.lemonade.com/_next/static/media/bg-switching.0c3ff5f6.webp?w=1200&q=100')"` in the CSS, NOT as inline style on the HTML element itself. The HTML element has no inline style attribute. The background-image is purely CSS-defined, not directly slottable as a background-image slot. Leave as static template content.

### Decisions surfaced by analysis

1. Synthesize `<main>` around sections 1–9.
2. No tag rewrites needed — all logical sections already use `<section>`.
3. Placeholder tweets (4x) and how-it-works captions (3x) → mark with `data-slot-skip="placeholder"`.
4. Head links to lift: preconnect fonts.googleapis.com, preconnect fonts.gstatic.com (crossorigin), Google Fonts stylesheet.
5. No inline scripts → no animations file needed.
6. asset strategy: "absolute" — all images already absolute CDN URLs.
7. Each product tile: the `<a>` wraps both `<img>` and `<span>` children that are also slots → slot the children individually (container-vs-children rule), not the `<a>`.
8. Bundle cards: same pattern — `<article>` wraps img+h4+p+a; slot children individually.
9. Impact badges: `<div>` wraps img+div; slot both children.
10. Tweet cards: entirely placeholders → data-slot-skip, no slots inside.
